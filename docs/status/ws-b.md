## Thu 9 Oct (Day 8)
- **Done:** the LLM generator, through Tencent Cloud ADP (`brain/gateway/adp.py`). The organizer's guide gives an ADP agent an Experience URL and an AppKey, not an OpenAI-compatible endpoint, so the gateway got an adapter for ADP's Chat API: the context packet is the one message, our JSON-claims instruction goes in `SystemRole` (overriding the agent's prompt for the turn), online search is disabled per turn, the reply is read from `response.completed` (or the streamed deltas), fenced or wrapped JSON is tolerated, and any error, throttling (one retry) or reply without claims is an abstain with the error code logged, never content. `GENERATOR_BACKEND` selects adp, openai or template; `auto` takes the first configured. The agent runs GPT-5.6 Terra (the picker's name, used as the audit label) with no knowledge base and search off.
- **Probed** (`python -m brain.gateway.probe`, check #1, ADR-001): reachable, 3 of 3 replies as JSON claims citing only packet documents, 2.9 to 13.9 s per call.
- **Tested:** 14 adapter tests against a fake Chat API. With ADP generating: all nine golden cases pass on the real pipeline in fixture mode (41 s), zero canaries across every persona and question (45 asks), chain verifies; on the real index with the simulators and real Slack and Drive, the seven non-scripted cases pass with grounding 1.0 on every answer, 4.5 to 17.7 s per question. Answers are now real prose with citations, for example scenario 1: "The database migration is currently in progress but blocked due to replica lag exceeding the 5-second threshold. Last week, blockers raised in Slack included replica lag as the main issue and a slow staging snapshot restore."
- **Changed in the fixtures:** scenario 2's golden rule now checks the new fact ("standby payment region") instead of the heading "failover step", which a real model paraphrases. Not a leak or a wrong answer; flagged here because the fixture is A's.
- **Seen and understood:** the model answers `"claims": []` with a one-line "the evidence does not contain X" when an asker's visible candidates do not cover the question (Jordan or Maya asking for the breach report). That is the right behaviour: it becomes an abstain, and it depends only on documents the asker may see.
